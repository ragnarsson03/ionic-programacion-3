> **Evaluación 1 — Programación III (Módulo 2)**
> Universidad Nacional Experimental de las Telecomunicaciones e Informática (UNETI)

Aplicación móvil híbrida construida con **Ionic Angular** que demuestra los conceptos fundamentales de componentes, enrutamiento y Data-Binding. La arquitectura del repositorio separa claramente el frontend del backend siguiendo los estándares de la industria.

---

## 🏛️ Arquitectura del Repositorio

```
ionic-programacion-3/
├── frontend/          ← Aplicación Ionic Angular (esta evaluación)
└── backend/           ← Reservado para futura API REST (NestJS / Express)
```

## ⚡ Inicio Rápido

```bash
# 1. Entrar a la carpeta del frontend
cd frontend

# 2. Instalar dependencias
npm install

# 3. Levantar el servidor de desarrollo local
npm start
# La app abre automáticamente en → http://localhost:4200
```
